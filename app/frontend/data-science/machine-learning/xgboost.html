2. Defina a pergunta

Classificação ou regressão?

Classificação prevê categorias, como “compra / não compra”. Regressão prevê valores numéricos, como o preço de venda. A sugestão automática é um ponto de partida; você pode alterá-la.

Features — quais variáveis ajudam a responder?

O target fica fora das entradas. Evite também identificadores e colunas que só ficam disponíveis depois do resultado.

Como os dados serão preparados?

Primeiro separamos treino e teste. Usamos a mediana do treino para números ausentes e uma categoria própria para textos ausentes. Categorias viram indicadores numéricos (one-hot). O teste e as novas previsões usam essa mesma preparação, sem reaprendê-la. Target ausente precisa ser corrigido no CSV.

Teste: 20%. Dados que não participam do treinamento.
Uma semente fixa permite repetir a divisão dos dados e o treino.

3. Configure o XGBoost

Cada nova árvore busca corrigir erros das anteriores. Comece com os valores sugeridos e observe os resultados.

4. Avalie e interprete

Importância das Variáveis

A importância indica a participação de cada variável no ganho total das árvores. Ela não significa necessariamente causalidade.

Como interpretar com cuidado

Importâncias são normalizadas pelo ganho total nas divisões das árvores; categorias da mesma feature são somadas. Valores correlacionados podem dividir importância. Uma métrica boa no teste não garante boas previsões fora desses dados. Evite ajustar repetidamente os parâmetros para melhorar sempre o mesmo teste.
